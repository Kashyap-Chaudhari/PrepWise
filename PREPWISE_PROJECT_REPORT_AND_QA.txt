PART 1: LITERATURE REVIEW
================================================================================

1.1 INTRODUCTION & BACKGROUND
Technical placement preparation is one of the most critical phases in higher
education for engineering and computer science graduates. Traditional placement
preparation approaches primarily involve scattered learning resources, textbooks,
independent coding platforms (e.g., LeetCode, HackerRank, GeeksforGeeks), and
static aptitude test booklets.

While these individual platforms serve specific niche domains, students face
significant challenges integrating quantitative aptitude, core computer science
fundamentals (Operating Systems, DBMS, Computer Networks, OOP), Data Structures &
Algorithms (DSA), coding practice in various programming languages, and mock
interviews into a single cohesive, trackable ecosystem.

--------------------------------------------------------------------------------
1.2 REVIEW OF EXISTING SYSTEMS
--------------------------------------------------------------------------------

1. LeetCode / HackerRank:
   - Strengths: Extensive collection of competitive coding and algorithmic problems;
     automated judge systems.
   - Limitations: Lacks comprehensive coverage of quantitative aptitude, verbal
     ability, core CS subjective/MCQ assessments, structured curriculum-aligned
     mock interviews, and personalized multi-domain progress tracking for college
     placements.

2. GeeksforGeeks / Sanfoundry:
   - Strengths: Vast textual tutorials and article-based MCQs across diverse CS
     domains.
   - Limitations: Fragmented user experience; limited real-time assessment feedback;
     lack of integrated timed testing environments and gamified streak trackers.

3. IndiaBIX / Testbook:
   - Strengths: Extensive aptitude and reasoning question banks.
   - Limitations: Static web interfaces without modern interactive coding sandboxes,
     AI-assisted interview evaluation, or personalized performance dashboards.

PART 2: PROPOSED SYSTEM ARCHITECTURE & DESIGN

2.1 SYSTEM OVERVIEW
PrepWise is an end-to-end, full-stack placement preparation web application designed
to streamline the campus recruitment journey. It consolidates Aptitude, Technical CS,
DSA, Multi-Language Coding, Mock Interviews, and visual progress analytics into a
single, intuitive, and responsive single-page application (SPA).

--------------------------------------------------------------------------------
2.2 KEY ARCHITECTURAL MODULES
--------------------------------------------------------------------------------

1. Authentication & Role Management Module:
   - JWT-based token authentication with bcrypt password hashing.
   - 1-click Demo accounts for instantaneous evaluator preview without cold-start delay.
   - Protected route middleware ensuring authenticated state across sessions.

2. Quantitative Aptitude & Reasoning Engine:
   - Categorized assessments: Quantitative Aptitude, Logical Reasoning, Verbal Ability.
   - Real-time countdown timer with auto-submission triggers.
   - Instant scoring breakdown (accuracy percentage, correct vs. wrong, review mode).

3. Technical Core CS Assessment Module:
   - 10 Subject tracks: Database Management Systems (DBMS), Operating Systems (OS),
     Computer Networks (CN), OOP, Java, C++, Python, SQL, Software Engineering,
     and Machine Learning.
   - Comprehensive explanations with references to standard computer science theory.

4. Data Structures & Algorithms (DSA) Engine:
   - 11 Topic categories: Arrays, Strings, Linked Lists, Stacks, Queues, Trees,
     Graphs, Recursion, Dynamic Programming, Sorting, and Searching.
   - Interactive hints, complexity analysis (Time & Space), and reference implementations.

5. Multi-Language Coding Sandbox:
   - 9 Programming Languages supported: Python, Java, C++, C, JavaScript,
     TypeScript, C#, PHP, SQL.
   - Problem statements with input/output specifications, edge case constraints,
     sample test cases, and optimal algorithmic solutions.

6. Visual Analytics & Gamification Engine:
   - Dynamic Chart.js visualizations for 30-day activity logs, topic accuracy bars,
     and overall accuracy doughnut charts.
   - Gamification mechanism: Daily streak counter, achievement badges, and global
     leaderboards.

[Q4] Category: Quantitative Aptitude | Topic: Pipes & Cisterns
Question: Pipe A can fill a tank in 6 hours and Pipe B can empty it in 8 hours. If both pipes are opened together, how long will it take to fill the tank?
Options:
  A) 24 hours
  B) 14 hours
  C) 12 hours
  D) 18 hours
Correct Answer: A) 24 hours
Explanation: Rate of Pipe A = +1/6 per hour. Rate of Pipe B = -1/8 per hour.
Net Rate = (1/6) - (1/8) = (4 - 3) / 24 = 1/24 tank per hour.
Time required to fill completely = 24 hours.

  C) 40
  D) 48
Correct Answer: A) 42
Explanation: Pattern 1: Differences are 4, 6, 8, 10, 12 (+2 increment). 30 + 12 = 42.
Pattern 2: n^2 + n -> 1^2+1=2, 2^2+2=6, 3^2+3=12, 4^2+4=20, 5^2+5=30, 6^2+6=42.

[Q1] Topic: Arrays | Problem: Two Sum Problem
Difficulty: Easy
Question: Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.
Options:
  A) O(N^2) Time, O(1) Space using brute force
  B) O(N log N) Time using Sorting & Two Pointers
  C) O(N) Time, O(N) Space using Hash Map
  D) All of the above are valid approaches
Correct Answer: D) All of the above are valid approaches
Explanation: The optimal approach uses a Hash Map in O(N) time and O(N) space.
Reference Solution (Java):
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int diff = target - nums[i];
            if (map.containsKey(diff)) return new int[]{map.get(diff), i};
            map.put(nums[i], i);
        }
        return new int[]{};
    }
}
```

[Q2] Topic: Arrays | Problem: Maximum Subarray (Kadane's Algorithm)
Difficulty: Medium
Question: What is the time complexity of Kadane's algorithm for finding the maximum sum contiguous subarray in an array of size N?
Options:
  A) O(N^2)
  B) O(N log N)
  C) O(N)
  D) O(2^N)
Correct Answer: C) O(N)
Explanation: Kadane's algorithm computes local and global maximums in a single pass O(N) time and O(1) auxiliary space.
Reference Solution (C++):
```cpp
int maxSubArray(vector<int>& nums) {
    int maxSoFar = nums[0], currMax = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        currMax = max(nums[i], currMax + nums[i]);
        maxSoFar = max(maxSoFar, currMax);
    }
    return maxSoFar;
}
```

[Q3] Topic: Strings | Problem: Valid Anagram
Difficulty: Easy
Question: Given two strings s and t, return true if t is an anagram of s. What is the optimal time complexity using character frequency counting?
Options:
  A) O(N^2)
  B) O(N)
  C) O(N log N)
  D) O(1)
Correct Answer: B) O(N)
Explanation: Counting frequencies with a 26-element array takes O(N) time and O(1) space.
Reference Solution (C++):
```cpp
bool isAnagram(string s, string t) {
    if (s.length() != t.length()) return false;
    int count[26] = {0};
    for (int i = 0; i < s.length(); i++) {
        count[s[i] - 'a']++;
        count[t[i] - 'a']--;
    }
    for (int c : count) if (c != 0) return false;
    return true;
}
```

[Q4] Topic: Linked List | Problem: Reverse Singly Linked List
Difficulty: Easy
Question: How many pointer variables are required to reverse a singly linked list iteratively in-place?
Options:
  A) 1 pointer
  B) 2 pointers
  C) 3 pointers (prev, curr, next)
  D) 4 pointers
Correct Answer: C) 3 pointers (prev, curr, next)
Explanation: `prev`, `curr`, and `next` pointers are required to update forward pointers backward without losing list references.
Reference Solution (C++):
```cpp
ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *curr = head, *next = nullptr;
    while (curr != nullptr) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

[L2] Language: Java | Topic: String Immutability & StringBuilder
Question: Why is StringBuilder preferred over String for repeated concatenations in a loop?
